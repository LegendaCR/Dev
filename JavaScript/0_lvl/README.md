## Заметки: JavaScript — ключевые характеристики

### 1. Уровень языка

JavaScript — **высокоуровневый** язык программирования. Он скрывает детали работы с железом и ОС: нет ручной работы с адресами памяти, указателями, регистрами.

### 2. Многоуровневость

Языковая модель одна: один синтаксис, одна модель выполнения, одни типы данных. Но **сред исполнения несколько**: браузер (DOM, события), Node.js, Electron, мобильные приложения, иногда IoT.

### 3. Типизация

**Динамическая типизация:** тип значения выясняется в рантайме; одна переменная может хранить разные типы.

```javascript
let x = 5;
x = "строка";
x = true;
```

Плюс — быстрое прототипирование. Минус — риск логических ошибок. **TypeScript** добавляет статическую типизацию поверх JS.

### 4. Память

**Автоматическое управление памятью** (Garbage Collector). Разработчик не выделяет и не освобождает память вручную. Когда на объект не остаётся ссылок, он становится кандидатом на сборку.

```javascript
let obj = { a: 1 };
obj = null;
```

При этом важно следить за утечками, замыканиями, глобальными ссылками, обработчиками событий.

### 5. Модель выполнения

**Один поток** в смысле выполнения JS-кода. Асинхронность — через event loop, очереди задач, колбэки, Promises, `async`/`await`. Это не параллельность «на ядрах», а кооперативная асинхронность.

### 6. Компиляция

**JIT:** код компилируется и оптимизируется во время работы. Движки разогревают частые участки и перекомпилируют их в более быстрый машинный код.

### 7. Парадигмы

**Мультипарадигменный:** процедурный, функциональный, ООП (прототипы), событийная модель.

### 8. Безопасность и доступ

Всё зависит от **среды**. В браузере — sandbox, нет прямого доступа к ФС. В Node.js — файлы, сеть, процессы.

### 9. Краткая сводка

| Параметр | Значение |
|----------|----------|
| Уровень | Высокоуровневый |
| Типизация | Динамическая |
| Память | Автоматическая (GC) |
| Потоки | Условно один (для кода) |
| Выполнение | JIT |
| Парадигмы | Несколько |
| Ручная память | Нет |

## Заметки: LEVEL 0 — базовые шаблоны

### 0.0 Общий шаблон файла (постоянный каркас)

```javascript
// 0.x_lvl.js

function solve(/* параметры */) {
  // твой код
}

// тесты
console.log(solve(/* вход */)); // ожидаемый результат
```

### 0.1 Переменные + `if` / `else`

Шаблон: проверка условия.

```javascript
function solve(x) {
  if (/* условие */) {
    // действие 1
  } else {
    // действие 2
  }

  return /* результат */;
}
```

**Когда:** диапазоны, категории, флаги (`true` / `false`).

### 0.2 `if` / `else if` / `else`

```javascript
function solve(x) {
  if (/* условие 1 */) {
    return /* A */;
  } else if (/* условие 2 */) {
    return /* B */;
  } else {
    return /* C */;
  }
}
```

**Когда:** несколько сценариев (возраст, тарифы, статусы).

### 0.3 Цикл `for` (базовый)

```javascript
function solve(n) {
  for (let i = 0; i < n; i++) {
    // логика
  }
}
```

**Стандарт:** `i` — индекс, `i < длина`, `i++`.

### 0.4 Накопление результата (`sum` / `count`)

```javascript
function solve(arr) {
  let result = 0;

  for (let i = 0; i < arr.length; i++) {
    result += arr[i];
  }

  return result;
}
```

**Когда:** сумма, количество, позже — максимум / минимум в том же духе.

## Заметки: массивы (core pattern)

### 1.0 Перебор массива

```javascript
function solve(arr) {
  for (let i = 0; i < arr.length; i++) {
    const current = arr[i];
    // работаем с current
  }
}
```

### 1.1 Поиск элемента (linear search)

```javascript
function solve(arr, target) {
  for (let i = 0; i < arr.length; i++) {
    if (arr[i] === target) {
      return i; // или true
    }
  }

  return -1; // или false
}
```

### 1.2 Фильтрация вручную (без `filter`)

```javascript
function solve(arr) {
  const result = [];

  for (let i = 0; i < arr.length; i++) {
    if (/* условие */) {
      result.push(arr[i]);
    }
  }

  return result;
}
```

### 1.3 Максимум / минимум

```javascript
function solve(arr) {
  let max = arr[0];

  for (let i = 1; i < arr.length; i++) {
    if (arr[i] > max) {
      max = arr[i];
    }
  }

  return max;
}
```

## Заметки: функции и стиль LeetCode

### Функция как «чёрный ящик»

```javascript
function solve(a, b) {
  // вход → обработка → выход
  return a + b;
}
```

**Правило:** функция получает данные, не «спрашивает» сама ввод, возвращает результат.

### Главный шаблон: Read → Think → Loop → Check → Update → Return

```javascript
function solve(arr) {
  let answer = /* стартовое значение */;

  for (let i = 0; i < arr.length; i++) {
    if (/* условие */) {
      // обновить answer
    }
  }

  return answer;
}
```

Такой формат хорошо совпадает с разбором задач на LeetCode: понять ограничения, выбрать инвариант, один проход, вернуть ответ.

## Новые задачи — полные условия (для решения)

Код пиши в файлах `0.4_lvl.js` … `0.6_lvl.js`. Ниже — формулировки в стиле платформ с задачами.

### 0.4 — Минимум в массиве

**Сложность:** Easy

**Описание:** Дан массив целых чисел `nums`. Найди **минимальное** значение среди всех элементов. Если массив **пустой**, верни `null`.

**Пример 1:** Ввод: `nums = [3, 1, 4, 1, 5]` — Вывод: `1`  
**Пример 2:** Ввод: `nums = [-2, -5, 0]` — Вывод: `-5`  
**Пример 3:** Ввод: `nums = []` — Вывод: `null`

**Ограничения:** `0 <= nums.length <= 10^4`, значения в допустимом диапазоне целых для JS.

**Функция:** `findMin(nums)`  
**Файл:** `0.4_lvl.js`

### 0.5 — Чётные числа

**Сложность:** Easy

**Описание:** Дан массив целых чисел `nums`. Подсчитай, сколько элементов **чётные** (делятся на `2` без остатка). Для отрицательных чисел используй обычное математическое правило чётности (`-4` — чётное).

**Пример 1:** Ввод: `nums = [1, 2, 3, 4, 5, 6]` — Вывод: `3`  
**Пример 2:** Ввод: `nums = [1, 3, 5]` — Вывод: `0`  
**Пример 3:** Ввод: `nums = []` — Вывод: `0`

**Ограничения:** `0 <= nums.length <= 10^4`

**Функция:** `countEvens(nums)`  
**Файл:** `0.5_lvl.js`

---

### 0.6 — Среднее арифметическое

**Сложность:** Easy

**Описание:** Дан непустой массив целых чисел `nums`. Верни **среднее арифметическое** всех элементов как число (допустимо вещественное, например `(1+2)/2 → 1.5`).

**Пример 1:** Ввод: `nums = [10, 20, 30]` — Вывод: `20`  
**Пример 2:** Ввод: `nums = [1, 2]` — Вывод: `1.5`  
**Пример 3:** Ввод: `nums = [7]` — Вывод: `7`

**Ограничения:** `1 <= nums.length <= 10^4`

**Функция:** `average(nums)`  
**Файл:** `0.6_lvl.js`
