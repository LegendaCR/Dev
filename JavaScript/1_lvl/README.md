# Level 1 — строки (LeetCode-style)

Строка в учебных задачах часто обходят как `str[i]` в цикле (аналогично массиву по индексу). Подходит уровень **Easy**.

## Задачи

| Файл | Условие (кратко) | Паттерн |
|------|------------------|---------|
| `1.1_lvl.js` | Подсчёт гласных букв в строке | проход + множество условий |
| `1.2_lvl.js` | Развернуть строку | проход с конца |
| `1.3_lvl.js` | Проверка палиндрома | сравнение / два указателя |
| `1.4_lvl.js` | Подсчёт одинаковых **соседних** символов | `str[i] === str[i - 1]` |
| `1.C1.js` | Подсчёт конкретного символа в строке | линейный проход |
| `1.C2.js` | Первая **неповторяющаяся** буква | вложенные циклы |
| `1.C3.js` | Удалить повторяющиеся **соседние** символы | накопление новой строки |
| `1.5_lvl.js` | Подсчёт согласных | как гласные, другой набор букв |

Запуск:

```bash

```

## Шпаргалка для этого уровня

### Перебор строки по индексу

```javascript
for (let i = 0; i < str.length; i++) {
  const char = str[i];
}
```

### Разворот через конкатенацию

Идея: идти `i` от `str.length - 1` до `0` и дописывать символы в новую строку (как в `1.2_lvl.js`).

### Палиндром

Сравнить строку с перевёрнутой копией **или** два указателя `left`, `right`, двигать к центру.

### Соседние символы

Всегда помнить про границу: для `str[i - 1]` цикл обычно начинают с `i = 1`, либо проверяют индекс.

### Частота символа без `Map` (учебный вариант)

Внешний цикл — кандидат на «уникальность», внутренний — сколько раз встречается (как в `1.C2.js`). Для интервью и LeetCode потом тот же смысл выражают через один проход и счётчик по алфавиту / `Map`.

## Связь с общим шаблоном (Level 0)

Тот же каркас **Read → Loop → Check → Update → Return**, только `arr.length` заменяется на `str.length`, а элемент — на `str[i]`.

Функция по-прежнему **чёрный ящик**: входные `str` (и при необходимости `char`) передаются аргументами, результат — `return`.

## Новые задачи — полные условия (для решения)

Код пиши в `1.5_lvl.js` … `1.7_lvl.js`.

### 1.5 — Согласные буквы

**Сложность:** Easy

**Описание:** Дана строка `s`, состоящая только из **строчных английских букв** `a`–`z`. **Гласные:** `a`, `e`, `i`, `o`, `u`. Все остальные буквы в этой задаче считаются **согласными**. Верни количество согласных в `s`.

**Пример 1:** Ввод: `s = "javascript"` — Вывод: `7` (не гласные: j,v,s,c,r,p,t)  
**Пример 2:** Ввод: `s = "aeiou"` — Вывод: `0`  
**Пример 3:** Ввод: `s = "bcd"` — Вывод: `3`

**Ограничения:** `0 <= s.length <= 10^4`, только `a`–`z`.

**Функция:** `countConsonants(s)`  
**Файл:** `1.5_lvl.js`

---

### 1.6 — Без пробелов

**Сложность:** Easy

**Описание:** Дана строка `s`. Построй и верни **новую** строку, в которой **все символы с кодом пробела** (обычный пробел `' '`) **удалены**. Остальные символы идут в том же порядке.

**Пример 1:** Ввод: `s = "a  b   c"` — Вывод: `"abc"`  
**Пример 2:** Ввод: `s = " nospaces "` — Вывод: `"nospaces"`  
**Пример 3:** Ввод: `s = "x"` — Вывод: `"x"`

**Ограничения:** `0 <= s.length <= 10^4`

**Функция:** `removeSpaces(s)`  
**Файл:** `1.6_lvl.js`

---

### 1.7 — Самая длинная «серия» одинаковых символов

**Сложность:** Easy

**Описание:** Дана строка `s`. Найди **максимальную** длину подряд идущих **одинаковых** символов. Если строка пустая, верни `0`. Для непустой строки ответ **не меньше 1**.

**Пример 1:** Ввод: `s = "aaabbbc"` — Вывод: `3` (три `a`).  
**Пример 2:** Ввод: `s = "ab"` — Вывод: `1`.  
**Пример 3:** Ввод: `s = ""` — Вывод: `0`.

**Ограничения:** `0 <= s.length <= 10^4`

**Функция:** `maxRunLength(s)`  
**Файл:** `1.7_lvl.js`
