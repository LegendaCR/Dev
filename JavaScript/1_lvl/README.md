# Level 1 — строки (LeetCode-style)

Строка в JS — **последовательность символов**; в учебных задачах её часто обходят как `str[i]` в цикле (аналогично массиву по индексу). Задачи уровня близки к **Easy / простому Medium** на [LeetCode](https://leetcode.com/problemset/): подсчёты, разворот, палиндром, работа с соседними символами, иногда вложенный цикл для «частоты» символа.

## Задачи

| Файл | Условие (кратко) | Паттерн |
|------|------------------|---------|
| `1.1_lvl.js` | Подсчёт гласных букв в строке | проход + множество условий / множество допустимых символов |
| `1.2_lvl.js` | Развернуть строку | проход с конца или с двух концов |
| `1.3_lvl.js` | Проверка палиндрома | сравнение с перевёрнутой копией или два указателя |
| `1.4_lvl.js` | Подсчёт одинаковых **соседних** символов | `str[i] === str[i - 1]` |
| `1.C1.js` | Подсчёт конкретного символа в строке | линейный проход (аналог frequency для одной буквы) |
| `1.C2.js` | Первая **неповторяющаяся** буква | вложенные циклы \(O(n^2)\); на LeetCode часто улучшают до \(O(n)\) через `Map` / массив частот — это следующий виток |
| `1.C3.js` | Удалить повторяющиеся **соседние** символы | накопление новой строки, сравнение с предыдущим символом |

Запуск:

```bash
node 1_lvl/1.1_lvl.js
```

---

## Шпаргалка для этого уровня

### Перебор строки по индексу

```javascript
for (let i = 0; i < str.length; i++) {
  const char = str[i];
}
```

### Разворот через конкатенацию

Идея: идти `i` от `str.length - 1` до `0` и дописывать символы в новую строку (как в `1.2_lvl.js`).

### Палиндром

Сравнить строку с перевёрнутой копией **или** два указателя `left`, `right`, двигать к центру.

### Соседние символы

Всегда помнить про границу: для `str[i - 1]` цикл обычно начинают с `i = 1`, либо проверяют индекс.

### Частота символа без `Map` (учебный вариант)

Внешний цикл — кандидат на «уникальность», внутренний — сколько раз встречается (как в `1.C2.js`). Для интервью и LeetCode потом тот же смысл выражают через один проход и счётчик по алфавиту / `Map`.

## Связь с общим шаблоном (Level 0)

Тот же каркас **Read → Loop → Check → Update → Return**, только `arr.length` заменяется на `str.length`, а элемент — на `str[i]`.

Функция по-прежнему **чёрный ящик**: входные `str` (и при необходимости `char`) передаются аргументами, результат — `return`.
