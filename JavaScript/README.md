# Обучение JavaScript на задачах

Здесь собраны **практические упражнения по JavaScript**: небольшие задачи с кодом в отдельных файлах, от простых к более осмысленным. Логика учёбы — **сначала уверенно оперировать базовым синтаксисом и циклами**, затем переходить к типичным приёмам работы с массивами и строками (в т.ч. *in-place* и два указателя), а дальше — к более «полноценному» JS (методы массивов, объекты, асинхронность и т.д.), когда дойдёшь до этих тем в курсе или по задачам.

Запуск примера (из корня этой папки):

```bash
node путь/к/файлу.js
```

## Структура папок

| Папка   | Смысл |
|--------|--------|
| `0_lvl` | Вводный уровень: **массивы**, цикл `for`, `if`, накопление результата, ранний выход, граничные случаи. |
| `1_lvl` | **Строки**: обход символов, сравнение, склейка, подсчёты, вложенный цикл для «частот». |
| `2_lvl` | **Массивы посложнее**: новый массив vs **изменение исходного массива (in-place)**, сдвиг «валидных» элементов, **два указателя** (разворот). |

Имена вроде `*.C*.js` — это условно «challenge» / чуть сложнее остальных в том же уровне.

## Направление обучения (что уже заложено в задачах)

По текущим файлам видно такую траекторию:

1. **Синтаксис и мышление как у программы** — функции, `return`, локальные переменные, проверки на пустой ввод / длину.
2. **Алгоритмы на массивах без «магии»** — всё через явный цикл, без опоры на `map`/`filter` (их можно добавить позже как второй слой).
3. **Строки как массивы символов** — индексация `str[i]`, обход с начала или с конца.
4. **Углубление** — второй максимум, первая уникальная буква (вложенные циклы), соседние дубликаты.
5. **In-place** — менять массив «на месте», возвращать длину полезного префикса (`compact`, удаление значения).
6. **Два указателя** — классический разворот массива.

То есть это в первую очередь **«язык + аккуратные циклы + типовые паттерны с собеседований/олимпиадного минимума»**, на которых потом легче строить уже **идиоматический JS**.

## Темы, которые по сути уже затронуты (по текущим файлам)

- Переменные (`const` / `let`), функции, `return`
- Массивы: длина, индекс, `push`, `slice`
- Циклы `for`, вложенные циклы
- Условия, счётчики, накопление суммы/строки
- Граничные случаи: пустая строка/массив, длина 1–2
- Базовые строковые задачи: разворот, палиндром, подсчёт символов
- In-place преобразование массива и шаблон «записываем в `arr[write]`»
- Два указателя для симметричного обхода

## Что логично изучать дальше (в репозитории этого ещё нет или мало)

Это ориентир «следующих слоёв», а не обязательный порядок:

- **Идиоматический JS по массивам/строкам** — `for...of`, методы `map`, `filter`, `reduce`, `find`, `includes`, `split`/`join`
- **Объекты и структуры данных** — объекты как словари, `Map` / `Set` (часто упрощают задачи на частотах)
- **Функции глубже** — области видимости, замыкания, стрелочные функции, колбэки
- **Классы и ООП в JS** (по желанию)
- **Асинхронность** — `Promise`, `async`/`await`, работа с API
- **Модули** — `import` / `export`
- **Ошибки** — `try` / `catch`, валидация входа
- **Окружение** — при желании: браузер (DOM), или Node.js (файлы, простой HTTP)
- **Качество кода** — линтер, форматтер, небольшие тесты (например, Vitest/Jest)

## Заметки по репозиторию

- В `2_lvl/2.4b_lvl.js` сейчас заглушка — задача про разворот массива **на месте** в процессе; в `2_lvl/2.4_lvl.js` уже есть рабочий разворот через два указателя (комментарий в файле про палиндром массива можно позже привести в соответствие с кодом или условием).
- Файл `0_lvl/0_С1.js` назван с буквой «С» кириллицы — от латинского `0_C1.js` отличается только символом в имени; при желании можно переименовать для единообразия.
