## 3.1 — Частоты чисел в массиве

**Сложность:** Easy

**Описание:**  
Дан массив целых чисел `nums`. Для каждого **значения**, которое встречается в массиве, нужно узнать, **сколько раз** оно встречается.

Реализуй функцию `frequencyMap(nums)`, которая возвращает **обект**: в качестве ключей — числа из массива (в JS ключи объекта всё равно будут строками при обычном доступе), в качестве значений — целые числа — количество вхождений.

**Пример 1:**

- **Ввод:** `nums = [1, 2, 2, 3, 1]`
- **Вывод:** объект, эквивалентный частотам: `1` встречается два раза, `2` — два раза, `3` — один раз  
  (например `{ "1": 2, "2": 2, "3": 1 }` — точный вид вывода `console.log` может отличаться порядком ключей, это нормально для обычного объекта)

**Пример 2:**

- **Ввод:** `nums = [5]`
- **Вывод:** один ключ с частотой `1`

**Ограничения:**

- `1 <= nums.length <= 10^4`
- `-10^9 <= nums[i] <= 10^9`

**Файл:** `3.1_lvl.js`

## 3.2 — Анаграмма

**Сложность:** Easy

**Описание:**  
Даны две строки `s` и `t`, состоящие только из **строчных латинских букв** `a`–`z`. Строка `t` — **анаграмма** строки `s`, если обе строки имеют одинаковую длину и одинаковые буквы с одинаковой кратностью (порядок не важен).

Реализуй функцию `isAnagram(s, t)`, возвращающую `true` или `false`.

**Пример 1:**

- **Ввод:** `s = "anagram"`, `t = "nagaram"`
- **Вывод:** `true`

**Пример 2:**

- **Ввод:** `s = "rat"`, `t = "car"`
- **Вывод:** `false`

**Ограничения:**

- `1 <= s.length, t.length <= 5 * 10^4`
- длины `s` и `t` при ответе `true` должны совпадать (это следует из определения)

**Файл:** `3.2_lvl.js`

## 3.3 — Пересечение двух массивов

**Сложность:** Easy

**Описание:**  
Даны два целочисленных массива `nums1` и `nums2`. Верни массив **уникальных** целых чисел, которые встречаются **и** в первом, **и** во втором массиве. Каждое число в ответе должно быть **один раз**. Порядок элементов в ответе **не важен**.

Реализуй функцию `intersection(nums1, nums2)`.

**Пример 1:**

- **Ввод:** `nums1 = [1, 2, 2, 3]`, `nums2 = [2, 3, 3, 4]`
- **Вывод:** массив, содержащий `2` и `3` (например `[2, 3]` или `[3, 2]`)

**Пример 2:**

- **Ввод:** `nums1 = [9, 4, 9, 8, 4]`, `nums2 = [4, 9, 5]`
- **Вывод:** `[9, 4]` (или `[4, 9]`)

**Ограничения:**

- `1 <= nums1.length, nums2.length <= 1000`
- `0 <= nums1[i], nums2[i] <= 10^9`

**Файл:** `3.3_lvl.js`

## 3.4 — Уникальные в отсортированном массиве (in-place)

**Сложность:** Easy

**Описание:**  
Дан целочисленный массив `nums`, отсортированный **по неубыванию**. Удали **дубликаты** так, чтобы каждое значение встречалось **не больше одного раза**, работая **внутри того же массива** (не создавай для этого второй массив как итоговое хранилище уникальных — модифицируй начало `nums`).

Реализуй функцию `removeDuplicatesSorted(nums)`, которая возвращает целое число `k` — количество уникальных значений. После вызова первые `k` элементов `nums` должны содержать эти уникальные значения **в отсортированном порядке**. Остальные элементы и то, что после позиции `k`, не проверяются.

**Пример 1:**

- **Ввод:** `nums = [1, 1, 2]`
- **Вывод:** `k = 2`, первые два элемента `nums` должны быть `[1, 2]`

**Пример 2:**

- **Ввод:** `nums = [0, 0, 1, 1, 1, 2, 2, 3, 3, 4]`
- **Вывод:** `k = 5`, префикс уникален: `[0, 1, 2, 3, 4]`

**Ограничения:**

- `1 <= nums.length <= 3 * 10^4`
- `-100 <= nums[i] <= 100`
- `nums` отсортирован по неубыванию

**Файл:** `3.4_lvl.js`

## 3.C1 — Два числа к цели (индексы)

**Сложность:** Easy

**Описание:**  
Дан массив целых чисел `nums` и целое число `target`. В массиве **ровно одна** пара различных индексов `i` и `j`, такая что `nums[i] + nums[j] == target`.

Верни массив из **двух индексов** `[i, j]` (порядок `i` меньше `j`, как в примере ниже — или любой договорённый; обычно возвращают в порядке возрастания индексов).

Реализуй функцию `twoSum(nums, target)`. Гарантируется, что решение существует и единственно с точки зрения пары индексов.

**Пример 1:**

- **Ввод:** `nums = [2, 7, 11, 15]`, `target = 9`
- **Вывод:** `[0, 1]`  
  **Пояснение:** `nums[0] + nums[1] == 9`

**Пример 2:**

- **Ввод:** `nums = [3, 2, 4]`, `target = 6`
- **Вывод:** `[1, 2]`

**Ограничения:**

- `2 <= nums.length <= 10^4`
- `-10^9 <= nums[i] <= 10^9`
- `-10^9 <= target <= 10^9`
- существует ровно одна корректная пара индексов

**Файл:** `3.C1.js`

## 3.C2 — Слияние двух отсортированных массивов

**Сложность:** Easy

**Описание:**  
Даны два массива целых чисел `arr1` и `arr2`, каждый **отсортирован по неубыванию**. Верни **новый** массив, содержащий все элементы обоих массивов, также отсортированный по неубыванию (по сути — стабильное слияние как в шаге merge-sort).

Реализуй функцию `mergeSorted(arr1, arr2)`. Не обязательно сортировать в конце — ожидается один линейный проход **двумя указателями**.

**Пример 1:**

- **Ввод:** `arr1 = [1, 3, 5]`, `arr2 = [2, 4, 6]`
- **Вывод:** `[1, 2, 3, 4, 5, 6]`

**Пример 2:**

- **Ввод:** `arr1 = [1, 2, 3]`, `arr2 = [1, 2, 3]`
- **Вывод:** `[1, 1, 2, 2, 3, 3]`

**Пример 3:**

- **Ввод:** `arr1 = []`, `arr2 = [1]`
- **Вывод:** `[1]`

**Ограничения:**

- `0 <= arr1.length, arr2.length <= 2000`
- массивы отсортированы по неубыванию

**Файл:** `3.C2.js`
