# Level 3 — объекты-словари, частоты и два указателя на отсортированных данных

После циклов, строк и **in-place** логично перейти к **подсчёту через объект** (`{}` как карта «ключ → число») и к задачам уровня **Easy / простой Medium** на [LeetCode](https://leetcode.com): [Two Sum](https://leetcode.com/problems/two-sum/), [Valid Anagram](https://leetcode.com/problems/valid-anagram/), [Intersection of Two Arrays](https://leetcode.com/problems/intersection-of-two-arrays/), [Remove Duplicates from Sorted Array](https://leetcode.com/problems/remove-duplicates-from-sorted-array/), слияние отсортированных массивов.

## Задачи

| Файл | Условие (кратко) | Идея |
|------|------------------|------|
| `3.1_lvl.js` | Частота каждого числа в массиве | объект `counts[x]`, накопление `(counts[x] \|\| 0) + 1` |
| `3.2_lvl.js` | Строки — анаграммы? | двойной проход: считаем буквы в `a`, вычитаем по `b` |

| `3.4_lvl.js` | Убрать дубликаты из **отсортированного** массива **in-place** | два индекса: `write` и `i`; сравниваем с последним уникальным |
| `3.C1.js` | **Two Sum**: два числа дают `target`, вернуть индексы | один проход + объект «значение → индекс», ищем `target - nums[i]` |
| `3.C2.js` | Слить два **отсортированных** массива | два указателя `i`, `j`; дописываем хвосты |

Запуск (из корня `JavaScript/`):


## Шпаргалка

### Объект как счётчик

```javascript
const count = {};
count[key] = (count[key] || 0) + 1;
```

Ключом может быть число (оно приведётся к строке в ключе объекта) или символ строки.

### Дубликаты в отсортированном массиве

Инвариант: префикс `arr[0..write-1]` — строго возрастающий без дубликатов; новый элемент сравнивается с `arr[write-1]`.

### Слияние отсортированных

Пока есть оба массива — забираем меньший головной элемент; затем дописываем остаток одного из них.

### Связь с уровнем 1 (`1.C2.js`)

Там первая уникальная буква решалась вложенными циклами. После **3.1** имеет смысл переписать ту идею через один проход и объект частот (отдельная задача для тренировки).
