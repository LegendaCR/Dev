## Шпаргалка: «новый массив» vs in-place

### Новый массив (`2.1_lvl.js`)

```javascript
const result = [];
for (let i = 0; i < arr.length; i++) {
  if (/* условие сохранить */) {
    result.push(arr[i]);
  }
}
return result;
```

Исходный `arr` не меняется.

### In-place с индексом записи (`2.2`, `2.3`)

```javascript
let write = 0;
for (let i = 0; i < arr.length; i++) {
  if (/* элемент оставляем */) {
    arr[write] = arr[i];
    write++;
  }
}
return write; // длина префикса «валидных» элементов
```

После вызова **смысл имеют** только `arr[0..write-1]`; хвост массива часто не важен (как в условиях LeetCode).

### Два указателя по краям (`2.4`)

```javascript
let left = 0;
let right = arr.length - 1;
while (left < right) {
  // swap arr[left], arr[right]
  left++;
  right--;
}
```

**Когда:** разворот, палиндром, пара суммы в **отсортированном** массиве (другие задачи).

## Связь с заметками Level 0

- Тот же **линейный проход** и мысленное **Read → Loop → Check → Update → Return**.
- In-place — это всё ещё один массив, но **инвариант**: «первые `write` позиций уже заполнены правильно».

Когда освоишь `filter` / `splice` в JS, вернись к этим задачам и сравни: **учебная ручная версия** помогает понимать, что делают стандартные методы и как оценивают память на собеседованиях.

### 2.5 — Только чётные (новый массив)

**Сложность:** Easy

**Описание:** Дан массив целых чисел `nums`. Верни **новый** массив, содержащий элементы `nums` **в исходном порядке**, но только те, которые **чётные** (как в задаче 0.5 по правилу чётности).

**Пример 1:** Ввод: `nums = [1, 2, 3, 4, 5, 6]` — Вывод: `[2, 4, 6]`  
**Пример 2:** Ввод: `nums = [1, 3, 5]` — Вывод: `[]`  
**Пример 3:** Ввод: `nums = []` — Вывод: `[]`

**Ограничения:** `0 <= nums.length <= 10^4`

**Функция:** `keepEvens(nums)`  
**Файл:** `2.5_lvl.js`

### 2.6 — Нули в конец (in-place)

**Сложность:** Easy

**Описание:** Дан массив целых чисел `nums`. **Переставь** элементы **на месте** так, чтобы все **`0`** оказались **в конце**, а все остальные числа шли **в начале** в **том же относительном порядке**, в каком были (устойчивость для ненулевых).

Функция может ничего не возвращать (`undefined`) или вернуть тот же `nums` — главное, чтобы после вызова исходный массив был изменён корректно.

**Пример 1:** Ввод: `nums = [0, 1, 0, 3, 12]` — после: `[1, 3, 12, 0, 0]`  
**Пример 2:** Ввод: `nums = [0, 0, 1]` — после: `[1, 0, 0]`  
**Пример 3:** Ввод: `nums = [1, 2, 3]` — без изменения порядка ненулевых: `[1, 2, 3]`

**Ограничения:** `1 <= nums.length <= 10^4`

**Функция:** `moveZeroes(nums)`  
**Файл:** `2.6_lvl.js`

### 2.7 — Неубывающий массив?

**Сложность:** Easy

**Описание:** Дан массив целых чисел `nums`. Верни `true`, если элементы идут **по неубыванию** (каждый следующий **не меньше** предыдущего). Для массива из **0 или 1** элемента считай условие выполненным.

**Пример 1:** Ввод: `nums = [1, 2, 2, 5]` — Вывод: `true`  
**Пример 2:** Ввод: `nums = [3, 2, 1]` — Вывод: `false`  
**Пример 3:** Ввод: `nums = []` — Вывод: `true`

**Ограничения:** `0 <= nums.length <= 10^4`

**Функция:** `isNonDecreasing(nums)`  
**Файл:** `2.7_lvl.js`
